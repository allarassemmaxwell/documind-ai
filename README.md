# DocuMind AI

Free and open-source AI-powered document assistant.

DocuMind AI aims to help users upload documents and ask questions about their content in English and French.

## Planned Features

- PDF and Word document uploads
- AI-powered question answering using retrieval-augmented generation (RAG)
- English and French language support
- Secure user authentication and private document access
- Open-source code and self-hosting instructions

## Project Status

🚧 Under active development. Features are planned and will be implemented and tested incrementally.
